# SquadLab Beta Testing

Thanks for helping test SquadLab.

The most useful beta feedback is not whether something "looks okay" — it is whether the app behaves properly when you actually use it alongside an NLM save.

## What I need testers to try

Please use SquadLab as you normally would and specifically test:

- Install SquadLab on Windows
- Create a save / club
- Add squad players
- Edit a player
- Change formation
- View Best XI & Bench
- Check Squad Health
- Use Tactic Effectiveness and switch formation
- Add scouted players
- Sort scouted players, including **Recent**
- Sign a scouted player
- Move a player on
- Start a new season
- Create / restore a backup
- Install a newer beta over an older version and confirm your data remains

## Reporting a bug

Please include:

1. **What were you trying to do?**
2. **What happened?**
3. **What did you expect to happen?**
4. **Which SquadLab version are you using?**
5. A screenshot if useful

Please use the **Bug report** issue template on GitHub.

## Suggesting a feature

Feature ideas are welcome, particularly things that make squad management easier without trying to turn SquadLab into a replacement for NLM.

Use the **Feature request** issue template.

## Important beta notes

- Windows only at the moment
- Player entry is currently manual
- SquadLab works from the attributes NLM shows at **Your Level**
- SquadLab does not know hidden NLM player values
- Current beta installers are not code-signed, so Windows may warn about an unknown publisher
- Squad data is stored locally on your PC

## Before installing an update

Updates are built to retain your local data, but during beta I still recommend:

**Backup & Import → Back Up Now**

before installing a new version.

## Discord feedback

If you came from Discord, screenshots and quick feedback there are also useful. For bugs I need to keep track of, a GitHub Issue is best because it stops reports disappearing into chat.
