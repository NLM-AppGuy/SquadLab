# SquadLab for NLM v3.4.0 Beta 1

I'm opening SquadLab up to a small group of beta testers.

## New in v3.4.0

### Tactic Effectiveness

SquadLab can now compare the supported formations against the players in your current squad.

For each formation it shows:

- Proposed XI Rating
- Natural XI coverage
- Weakest starter
- Bench rating
- Difference versus your current formation

You can then select a formation and make it your new default across SquadLab.

## Core SquadLab features

- Positional player ratings using NLM **Your Level** attributes
- Best XI
- Recommended bench
- Squad Health
- Recruitment priorities
- Scouted-player comparison
- Sign Player
- Players to Move On
- Multiple saves / clubs
- Seasons
- Local backups and restore

## Beta notes

- Windows only currently
- Player entry is manual at this stage
- Your data is stored locally
- The installer is currently unsigned, so Windows may display an **Unknown publisher** warning

If Windows SmartScreen appears after downloading from this official release:

**More info → Run anyway**
