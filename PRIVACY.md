# Privacy

SquadLab is designed as a **local-first** application.

## What is stored

SquadLab can store information you enter about:

- Clubs / saves
- Seasons
- Players
- Player attributes
- Scouted players
- Squad status and decisions
- App settings

This information is stored locally on your PC in SquadLab's local application/browser data.

## Accounts

SquadLab does not currently require a user account.

## Cloud database

SquadLab does not currently send your squad database to an NLM App Guy cloud service.

## Backups

If you export a SquadLab backup, the resulting backup file is yours to store wherever you choose.

## External links

SquadLab may contain links to external services or websites such as Ko-fi, GitHub and FFN. Those services have their own privacy policies.

## Beta software

SquadLab is currently beta software. You should keep periodic backups of data you do not want to re-enter.
